# SmartPark Management System

SmartPark Management System is a smart parking solution designed to simplify parking slot management, vehicle booking, payment processing, and revenue monitoring.

The system provides dynamic parking slot allocation based on vehicle type and availability. Users can register, reserve parking slots, and make payments, while administrators can monitor users, bookings, parking status, and revenue through a centralized dashboard.

## Key Features

* 🚗 Dynamic parking slot allocation
* 🅿️ Real-time slot availability
* 📅 Parking booking and reservation
* 💳 Payment management
* 📊 Revenue and parking analytics
* 👤 User management
* ⚙️ Admin monitoring dashboard
* 💾 Data persistence using browser storage

## Purpose

The main goal of SmartPark is to reduce parking search time, improve parking-space utilization, and provide a simple and efficient parking management experience.
